# OverZone Scanner

Считает сигналы индикатора OverZone сам и шлёт их в Telegram. TradingView в
цепочке не нужен: расчёт идёт по коду, сверенному с ним бар в бар, поэтому нет
ни лимита на число алертов, ни платного вебхука. Монет может быть сколько угодно.

## Что важнее оповещений

Каждый сигнал в момент появления записывается в `signals.csv` — с ценой входа,
стопом и целью. Через месяц это будет **форвардная выборка**: данные, собранные
вперёд, а не нарезанные из прошлого. У неё нет ни подгонки под историю, ни
ошибки выжившего, ни сомнений в том, что расчёт подсматривал будущее.

Backtest на истории такого дать не может в принципе.

## Настройка

1. Создать репозиторий на GitHub и залить эту папку.
2. Settings → Secrets and variables → Actions → New repository secret:
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather
   - `TG_CHAT_ID` — `@имя_канала` или числовой id чата
3. Вкладка Actions → включить workflows.
4. Там же кнопка **Run workflow** — первый запуск вручную, чтобы проверить.

Дальше запускается сам каждые 15 минут.

## Параметры — `config.json`

| Поле | Смысл |
|---|---|
| `symbols` | список инструментов Binance USDT-M |
| `interval` / `tfm` | таймфрейм и он же в минутах |
| `x_dev` | отклонение от зоны, % — 0.3 по результатам проверки |
| `stop_swing_bars` | стоп за экстремум N баров |
| `target_r` | цель в кратных риска |
| `max_hold_bars` | предохранитель по времени |

Значения по умолчанию — те, что показали себя лучше остальных на проверке с
делением истории пополам. Это не гарантия прибыли: перевес подтверждён только
на крупных ликвидных парах и статистически незначим. Размер позиции
соответственно.

## Запуск локально

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=...
export TG_CHAT_ID=...
python scan.py
```

Без переменных окружения скрипт всё равно посчитает сигналы и запишет журнал,
просто не станет ничего отправлять — удобно для проверки.

## Файлы

| Файл | Назначение |
|---|---|
| `oz.py` | порт индикатора, сверенный с TradingView |
| `scan.py` | сканер: загрузка свечей, сигналы, отправка, журнал |
| `signals.csv` | журнал сигналов — растёт сам, его не редактировать |
| `state.json` | последний обработанный бар по каждой монете |
